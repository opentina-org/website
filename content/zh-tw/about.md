## 使命

OpenTina 是一個開源社群，致力於為**全志（Allwinner）A733** 晶片平台提供底層系統軟體與多作業系統發行版支援。我們的目標是打造穩健、生產等級的軟體生態：及時維護的板級支援、主線核心整合，以及可重現的系統建置管線。

## 專案如何組織

一切都位於 GitHub 的 [opentina-org](https://github.com/opentina-org) 組織下：

- **程式碼** —— 硬體支援與 BSP 元件（[build](https://github.com/opentina-org/build)、[linux](https://github.com/opentina-org/linux)、[u-boot](https://github.com/opentina-org/u-boot)、[trusted-firmware-a](https://github.com/opentina-org/trusted-firmware-a)、[optee_os](https://github.com/opentina-org/optee_os)、[awbin](https://github.com/opentina-org/awbin)、[xfel](https://github.com/opentina-org/xfel)）。
- **發行版** —— [buildroot](https://github.com/opentina-org/buildroot)、[openwrt](https://github.com/opentina-org/openwrt)、[meta-opentina](https://github.com/opentina-org/meta-opentina)、[debian](https://github.com/opentina-org/debian)、[ubuntu](https://github.com/opentina-org/ubuntu)。
- **文件** —— 指南與技術參考位於 [docs](https://github.com/opentina-org/docs)。
- **社群** —— [opentina](https://github.com/opentina-org/opentina) 元倉庫承載全專案的 [issue 跟蹤](https://github.com/opentina-org/opentina/issues)；組織預設設定位於 [.github](https://github.com/opentina-org/.github)。

## 參與貢獻

OpenTina 在公開環境中開發：

1. 在 issue 跟蹤中找到想做的事情。
2. Fork 相關倉庫並提交 Pull Request。
3. 討論、迭代、合併。

錯誤報告、問題與 Pull Request 均受到歡迎。如果不確定從哪裡開始，歡迎在 [opentina](https://github.com/opentina-org/opentina/issues) 提交 issue，社群會為你指明方向。
