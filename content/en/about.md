## Mission

OpenTina is an open-source community dedicated to providing low-level system software and multi-OS distribution support for the **Allwinner A733** chip platform. Our goal is a robust, production-grade software ecosystem: up-to-date board support, mainline kernel integration, and reproducible system build pipelines.

## How the project is organized

Everything lives on GitHub under the [opentina-org](https://github.com/opentina-org) organization:

- **Code** — hardware enablement and BSP components ([build](https://github.com/opentina-org/build), [linux](https://github.com/opentina-org/linux), [u-boot](https://github.com/opentina-org/u-boot), [trusted-firmware-a](https://github.com/opentina-org/trusted-firmware-a), [optee_os](https://github.com/opentina-org/optee_os), [awbin](https://github.com/opentina-org/awbin), [xfel](https://github.com/opentina-org/xfel)).
- **Distributions** — [buildroot](https://github.com/opentina-org/buildroot), [openwrt](https://github.com/opentina-org/openwrt), [meta-opentina](https://github.com/opentina-org/meta-opentina), [debian](https://github.com/opentina-org/debian), [ubuntu](https://github.com/opentina-org/ubuntu).
- **Documentation** — [docs](https://github.com/opentina-org/docs) for guides and technical references.
- **Community** — the [opentina](https://github.com/opentina-org/opentina) meta-repo hosts the project-wide [issue tracker](https://github.com/opentina-org/opentina/issues); organization defaults live in [.github](https://github.com/opentina-org/.github).

## Contributing

OpenTina is developed in the open:

1. Find something to work on in the issue tracker.
2. Fork the relevant repository and open a pull request.
3. Discuss, iterate, and merge.

Bug reports, questions and pull requests are all welcome. If you are unsure where to start, open an issue in [opentina](https://github.com/opentina-org/opentina/issues) and the community will point you in the right direction.
