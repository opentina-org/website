## Misión

OpenTina es una comunidad de código abierto dedicada a proporcionar software de sistema de bajo nivel y soporte de distribuciones multi-SO para la plataforma de chips **Allwinner A733**. Nuestro objetivo es un ecosistema de software sólido y de calidad industrial: soporte de placas actualizado, integración con el kernel mainline y pipelines de construcción reproducibles.

## Cómo se organiza el proyecto

Todo reside en GitHub bajo la organización [opentina-org](https://github.com/opentina-org):

- **Código** — habilitación de hardware y componentes BSP ([build](https://github.com/opentina-org/build), [linux](https://github.com/opentina-org/linux), [u-boot](https://github.com/opentina-org/u-boot), [trusted-firmware-a](https://github.com/opentina-org/trusted-firmware-a), [optee_os](https://github.com/opentina-org/optee_os), [awbin](https://github.com/opentina-org/awbin), [xfel](https://github.com/opentina-org/xfel)).
- **Distribuciones** — [buildroot](https://github.com/opentina-org/buildroot), [openwrt](https://github.com/opentina-org/openwrt), [meta-opentina](https://github.com/opentina-org/meta-opentina), [debian](https://github.com/opentina-org/debian), [ubuntu](https://github.com/opentina-org/ubuntu).
- **Documentación** — guías y referencias técnicas en el repositorio [docs](https://github.com/opentina-org/docs).
- **Comunidad** — el repositorio meta [opentina](https://github.com/opentina-org/opentina) alberga la [gestión de incidencias](https://github.com/opentina-org/opentina/issues) del proyecto; las convenciones de la organización están en [.github](https://github.com/opentina-org/.github).

## Contribuir

OpenTina se desarrolla en abierto:

1. Encuentre una tarea en la gestión de incidencias.
2. Haga fork del repositorio correspondiente y abra un pull request.
3. Discuta, itere y fusione.

Se aceptan informes de errores, preguntas y pull requests. Si no sabe por dónde empezar, abra una incidencia en [opentina](https://github.com/opentina-org/opentina/issues) y la comunidad le orientará.
